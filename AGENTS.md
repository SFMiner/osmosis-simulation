# Project conventions

- The neutral-size outline is a fixed reference at the profile's initial radius (setting 0), not a target challenge: students compare swelling and shrinking against the normal cell.

- The lowest setting (-5) is solute-free in both model and particles; 0 remains the normal starting match. Pure water has no finite equilibrium, so preserve the size bound and identify it as a display limit.
- Displayed radius changes are amplified 2× around the fixed neutral radius; keep the membrane and particle boundary on the same published radius. The center is raised to leave room for maximum swelling above the controls.
- Red blood cell mode is a separate top-button view with independent per-cell water state and irreversible rupture; mode switches/reset create a neutral population. Pause freezes drift and fading. Average readouts exclude burst cells; the original single-cell mode never bursts.
